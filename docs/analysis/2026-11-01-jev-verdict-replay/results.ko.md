## 질문 1판 (배포된 J1 질문)

"이 제안을 최종 결정으로 받아들여야 하는가? 예: 비평이 제기한 막는 문제가 모두 답해졌다."

| | LLM 승인 (52) | LLM 거부 (8) |
|---|---|---|
| jev 승인 (p ≥ 0.8) | 0 | 0 |
| jev 거부 (p ≤ 0.2) | 48 | 8 |
| 불확실 | 4 | 0 |

`p_approve` 중앙값 0.06(LLM 승인)과 0.05(거부), 순위 AUC 0.68. jev는 거의 모두 거부했다: 한 라운드에서 비평은 제안 뒤에
나오므로 제안은 비평에 답할 수 없고, jev는 정확히 그것에 답했다(LLM이 승인한 곳에서도 `p_blocking` 중앙값 0.91). 질문이
토론에 맞지 않았다.

## 질문 2판 (토론 구조에 맞춰 씀)

같은 자료에서 비교하려고 한 요청으로 물었다:

- `decide_now`: 판정자가 비평의 타당한 점을 받아들여 지금 최종 결정을 쓸 수 있는가(예: 좋은 바탕이고 비평은 결정 안에서
  정리 가능, 아니오: 근본이 틀려 먼저 다시 써야 함)?
- `fundamental`: 비평이 결정 안에서 고칠 수 없는 결함을 보여 주는가?
- `next_step`: 승인과 다시 쓰기 중 선택.

| 질문 | 중앙값, LLM 승인 / 거부 | AUC |
|---|---|---|
| `decide_now` | 0.74 / 0.66 | 0.69 |
| `fundamental` (낮을수록 승인) | 0.38 / 0.54 | 0.77 |
| `next_step` (승인 확률) | 0.43 / 0.41 | 0.54 |
| 근거 점수 | 1.69 / 1.25 | 0.67 |

설계의 임계값 0.8 / 0.2로 본 `decide_now`:

| | LLM 승인 (52) | LLM 거부 (8) |
|---|---|---|
| jev 승인 | 13 | 0 |
| jev 거부 | 3 | 0 |
| 불확실 (-> LLM 판정자) | 36 | 8 |

0.7 / 0.3이면 승인 34(LLM이 거부한 것 2), 거부 4(LLM이 거부한 것 1), 불확실 22. `decide_now`는 jev 게이트의 이후
`PASSED`와 `DISPUTED`를 구별하지 못한다(AUC 0.41).

## 해석

- **0.8에서 잘못된 승인은 없다.** jev가 확신해 승인한 13건은 모두 LLM도 승인했다. 추측하는 대신 "모름"이라고 했다.
- **거부하지 못한다.** LLM이 거부한 8건 중 jev가 확신해 거부한 것은 없다. 임계값을 낮추면 범위는 넓어지지만 잘못된 승인이
  생긴다.
- **아낄 것이 적다.** 설계 A에서 LLM 판정 차례는 jev가 거부할 때만 줄어든다(승인해도 작성자가 필요). 이 숫자로는 A가 호출을
  거의 줄이지 못한다.
- **한계.** 거부는 8건뿐이고 그중 5건은 10월 초 대화 기록으로 다시 만들었다. 질문 2판은 같은 데이터로 쓰고 쟀으므로 결과가
  좋게 나오기 쉽다.

## 결정

그림자 모드는 질문 2판으로 바꾼다(결정 질문 `approve`가 `decide_now`, 그리고 `fundamental`, 근거. 기록은 `questions: 2`를
갖고 보고서는 그것만 센다). 이 근거로 J3는 시작하지 않는다. J2는 운영 토론에서 새로 쌓이는 그림자 기록으로 판단한다.
