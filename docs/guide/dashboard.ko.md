# 대시보드 사용법

[English](dashboard.md) | 한국어

[사용 가이드](README.ko.md)로 돌아가기.

대시보드는 허브 에이전트가 `9870` 포트(`127.0.0.1`과 허브 Tailscale IP, 공인 IP에는 열지 않음)에서 직접 제공하며,
Tauri 2 데스크톱 앱(`apps/web-desktop`)으로도 사용할 수 있다.

## 연결과 로그인

1. 브라우저에서 `http://<허브 Tailscale IP>:9870/`을 열거나 데스크톱 앱을 실행해 허브 URL을 입력한다.
2. 허브의 `~/.guardian/agent.env`에 들어 있는 `AGENT_TOKEN` 값을 입력해 로그인한다.
3. 허브는 토큰을 `HttpOnly` 세션 쿠키로 교환한다. 허브를 바꾸거나 로그아웃하려면 상단 헤더의 **허브 연결** 또는
   **설정 > 허브 연결**을 사용한다.

대시보드 기본 언어는 **한국어**다. 영어 전환은 **설정 > 화면**에서 할 수 있으며(브라우저별 저장, 페이지 새로고침
적용), 모든 화면 문구는 양쪽 언어로 동일하게 제공된다.

## 주 메뉴 구성

대시보드는 다섯 개의 주 목적지로 구성된다.

| 메뉴 | 라우트 | 주요 용도 |
|---|---|---|
| **현황** | `#/overview` | 지금 주의가 필요한 항목 요약(노드 도달성, 허브 CPU/메모리/디스크, SSH 감사 요약, 대기 중 승인, 최근 토론) |
| **노드** | `#/fleet` | 노드 인벤토리, 노드 그룹, 플릿 SSH 감사, 원격 명령 실행, 명령 세트 관리 |
| **업무 흐름** | `#/debates` | 토론 시작·모니터링, 빠른 질문, 상주 에이전트 모니터, 코드 위키·산출물·결과물 조회 |
| **승인** | `#/approvals` | 제안된 개별 액션과 다중 노드 계획 검토·실행·거절 |
| **설정** | `#/settings` | 허브 연결, 흐름 구성(프로젝트·흐름·캐릭터), 실행 환경(워커), 화면 설정 |

## 1. 현황 (`#/overview`)

운영 상태를 한눈에 확인하는 첫 화면이다.
- **노드 도달성**: 최근 플릿 진단 기준 온라인/오프라인 노드 수를 표시하며, 오프라인 노드 목록으로 바로 이동하거나
  플릿 대상 운영 토론을 시작할 수 있다.
- **허브 메트릭**: 허브의 CPU, 메모리, 디스크 사용률을 5초 간격으로 표시한다.
- **SSH 감사**: 플릿 평균 점수와 실패 규칙이 있는 노드를 요약한다.
- **승인·토론**: 현재 선택한 프로젝트의 승인 대기 액션과 최근 토론 5건을 표시한다.

## 2. 노드 (`#/fleet`)

다섯 개 탭으로 플릿 전반을 관리한다.

- **노드 (`#/fleet/nodes`)**: 상태(`전체` / `온라인` / `오프라인`)·그룹별 필터링, 상세 열(아키텍처, 메시 IP, 프로브)
  표시 전환, 허브 프로세스 확인, tailnet 메시 가입 대기 노드 승인·해제, 새 노드 등록(`#/fleet/nodes/new`), 노드 클릭 시
  상세 페이지(`#/fleet/nodes/<id>`) 열기.
- **그룹 (`#/fleet/groups`)**: 정적·규칙 기반 동적 노드 그룹을 실시간 구성원 미리 보기와 함께 생성·편집한다.
- **SSH 감사 (`#/fleet/ssh`)**: 플릿 전체 또는 대상 노드의 SSH 보안 감사(`SEC-SSH-001`~`005`)를 실행·새로 고치고,
  노드별 유효 `sshd` 설정과 `authorized_keys` 지문을 확인한다.
- **명령 (`#/fleet/commands`)**: 단일 노드, 노드 그룹 또는 `all`에 단발 명령이나 명령 세트를 병렬 실행하고 스트리밍
  출력과 실행 이력을 확인한다.
- **명령 세트 (`#/fleet/commandSets`)**: 일괄 실행에 쓰이는 재사용 명령 세트를 조회·편집·확정한다.

## 3. 업무 흐름 (`#/debates`)

상단 **프로젝트 전환기**로 작업할 프로젝트를 고른다. 프로젝트 종류에 따라 표시되는 탭이 달라진다.

- **토론 (`#/debates`)**: **새 토론**으로 토론을 시작한다(흐름 선택 또는 프로젝트 기본 흐름, 자리별 캐릭터 교체,
  최대 라운드, `--context-path` 지정). 실행 중에는 실시간 모니터가 토론 에이전트 레인, 코드·노드 조회 단계, 타임라인을 보여
  준다. 완료되면 판정 결과, `jev` 게이트 결과, 제안된 액션, **이어가기**, **다시 실행**, **게시**(코드 프로젝트)를
  사용할 수 있다. 닫힌 스레드는 **닫힌 토론 보기**로 표시한다.
- **빠른 리뷰 (`#/debates/review`, 코드 프로젝트, 첫 탭)**: 변경 하나(커밋 범위 `BASE..HEAD` 또는 붙여 넣은 패치)를 건네면
  읽기 전용 리뷰어 한 명이 지적을 남긴다. 라벨은 `REVIEW`(자문, 판정자 없음, 액션 없음). 지적마다 인용한 줄이 실제로 있는지
  확인하고, 바뀐 줄과 관계없는 지적은 notes로 따로 둔다. **토론으로 넘기기**로 변경과 지적을 토론의 공용 마감에 넘긴다.
  CLI: `guardian.py --review --project ID --range BASE..HEAD`, API: `POST/GET /api/reviews`.
- **빠른 질문 (`#/debates/ask`)**: 판정자와 액션 없이 단일 역할에 읽기 전용 질문을 보낸다(`SOLO`). 프로젝트 맥락
  질문과 **일반 모드**(프로젝트 없음)를 모두 지원하며, 허브에 설치된 제공자 중 원하는 것을 고를 수 있다.
- **상주 에이전트 (`#/debates/residents`)**: 허브 전체의 Tier-1 상주 에이전트 상태, 최근 턴, 메일 목록(클릭 시 비밀값
  마스킹된 본문 열람), 작업 보드, 저장소 이벤트를 읽기 전용으로 모니터링한다(화면이 보일 때 10초마다 갱신).
- **위키 (`#/debates/wiki`, 코드 프로젝트 전용)**: 생성된 코드 위키를 **읽기**, **파일**, **이력** 모드로 탐색하고
  `[[페이지]]` 내부 링크 이동 및 수동 재빌드를 수행한다.
- **산출물 (`#/debates/artifacts`, 설계 프로젝트 탭; 다른 프로젝트에서도 링크로 열람 가능)**: 토론이 작성한 버전별
  Markdown 문서와 다이어그램을 확인한다.
- **결과물 (`#/debates/results`)**: 선택한 프로젝트의 모든 스레드 보고서와 산출물을 모아 본다.

### 오피스 내보내기와 다이어그램

- 보고서 안의 Mermaid 다이어그램은 인라인 렌더링되며 **`.mmd`로 저장** 버튼을 제공한다.
- `code`·`ops` 토론 보고서에서 **문서로 보관**을 누르면 `report.md`가 산출물 버전으로 저장된다(기본 30일 보관).
- **산출물** 뷰어에서 저장된 Markdown 버전을 **Word(`.docx`)** 또는 **PowerPoint(`.pptx`)** 파일로 변환해 내려받을
  수 있다.

## 4. 승인 (`#/approvals`)

선택한 프로젝트의 다중 노드 **계획**과 개별 **액션**을 승인 대기 항목 우선으로 표시한다.

- 항목을 클릭하면(`#/approvals/<id>` 또는 `#/approvals/plan_<id>`) 미리 보기, diff, 드리프트 검사, `jev` 게이트 및
  비평가 투표 결과를 상세히 볼 수 있다.
- 실행 전 확인 창이 뜨며, **고위험(high)** 액션은 액션 번호를 직접 입력해야 실행된다.
- 대시보드에서 내린 결정은 감사 이력에 `dashboard@<IP>`로 기록된다.
- 허브에 `GUARDIAN_UI_ACTIONS=off`가 설정되어 있으면 대시보드의 실행·거절·게시·닫기 동작이 차단되며, `403` 안내에
  대신 실행할 CLI 명령이 표시된다.

## 5. 설정 (`#/settings`)

설정은 네 가지 묶음으로 나뉜다.

- **허브 연결 (`#/settings/endpoint`)**: 연결된 허브 URL 확인, URL 변경, 로그아웃.
- **흐름 구성 (`#/settings/flowConfig`)**: **프로젝트**(`code`/`ops`/`design` 정의, 클론·동기화, 야간 감시·일괄 실행
  정책, 흐름을 고르지 않고 시작한 토론의 **기본 흐름**), **흐름**(`#/settings/flows`: `@xyflow/react` 기반 흐름 편집기로
  자리, 동시 묶음, 연결, 받는 방식(`원문`, `요약`, `핵심만`, `최신만`), 정리자, 공통 마감, 자리별 제공자·실행 호스트·저장소
  도구), **캐릭터**(`#/settings/personas`: 에이전트 캐릭터 조회·편집, **AI로 제안**, 린트 경고)를 전환하며 편집한다. 팀은
  흐름으로 보이며, 팀 편집기는 2026-11-23에 없앴다([대시보드 검토](../design/ui-verification-review.ko.md)). 팀 파일은 CLI용으로
  남는다. 옛 해시(`#/settings/teams`, `#/debates/templates`, `#/debates/personas`)는 새 위치로 열린다.
- **실행 환경 (`#/settings/workers`)**: 워커로 참여 중인 Tier-1 노드, 프로토콜 버전, 설치된 제공자, 동시 실행 수
  (`max_jobs`)를 확인한다.
- **화면 (`#/settings/display`)**: 대시보드 언어(한국어/영어)를 변경한다. (데스크톱 앱의 내보내기 폴더는 2026-11-24에
  없앴다. 데스크톱 앱은 Markdown을 다운로드 폴더에 저장하고, 다른 파일은 브라우저에서 내려받는다.)
